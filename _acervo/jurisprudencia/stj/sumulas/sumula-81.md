# Súmula nº 81 do STJ

*DIREITO PROCESSUAL PENAL - FIANÇA*

**Situação:** Vigente (BNP/CNJ, atualização 01/04/2025)

## Enunciado

Não se concede fiança quando, em concurso material, a soma das penas mínimas cominadas for superior a dois anos de reclusão.
